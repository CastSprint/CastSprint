# Installation guide

1. Open `CastSprint-<version>-macOS.dmg`.
2. Drag CastSprint to Applications.
3. Eject the disk image.
4. Launch CastSprint from Applications.
5. Grant only the permissions required by the feature you start.

Official public distribution must be Developer ID signed, notarized, stapled, and pass Gatekeeper assessment. A local ad-hoc build is for development only.
