# Canvas Presets

- Source Native: follows the current source aspect.
- 1920×1080 and 1280×720: fixed 16:9 presentation.
- 1080×1920 and 720×1280: fixed 9:16 presentation.

Presets select presentation geometry; they do not change or misrepresent capture resolution. Current rendering is FIT with explicit letterboxing. FILL, stretch, blurred, and transparent backgrounds remain unimplemented.
